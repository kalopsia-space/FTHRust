# Third-Party Notices — FTHRust (FTHR Clips)

FTHRust bundles and links against third-party software. This file lists every
component that is distributed in the AppImage, its licence, and where to find
the full licence text.

FTHRust's own source code is licensed **GPL-3.0-only** (see
[`LICENSE`](LICENSE)). Third-party components and project assets identified
below keep their own licences. Full licence texts live in
[`licenses/`](licenses/) and ship inside the AppImage next to this file.

This file is generated by `tools/gen-notices.sh` from
`packaging/notices/header.md`, the FFmpeg manifest and library list in
`packaging/`, and the Cargo dependency graph; CI fails when it is out of date.

## Not distributed

These come from the user's system and are never bundled:

- **PipeWire** — `fthrust`, `fthrust-engine` and the portal code link
  `libpipewire-0.3.so.0` directly; the host's library must match the host's
  PipeWire daemon, so it is not shipped.
- **libva, VA-API drivers, CUDA/NVENC drivers, Vulkan and GL drivers** —
  loaded at run time by FFmpeg and wgpu from the host.
- **libwayland and libxkbcommon** — loaded with `dlopen()` by the Wayland
  crates.
- **glibc** (`libc`, `libm`, `libpthread`, `libdl`, `librt`, `libmvec`) and
  `libgcc_s`.
